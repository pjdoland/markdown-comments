Repo Notepad Comments

Comments on Markdown files, stored inside the file itself.

Reading public repositories works without a token. A token is needed to post comments, and to read private repositories.

  1. Create a fine-grained personal access token.
  2. Give it Contents: read and write on the repositories you want to comment in.
  3. Paste it below. It is stored in this browser's extension storage and sent only to api.github.com.

A valid token is not the same as a token that can reach a given repository. Fine-grained tokens are granted per repository, and one that was not granted this repository looks identical to one where the file does not exist.

Comments are written into the Markdown file as a footnote block, so they stay readable on github.com for people without this extension, and the same files can be edited in RepoNotepad.
